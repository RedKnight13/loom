What it will do

  1. Check prerequisites and report versions.
  2. Clone Loom to ~/loom, refusing a dirty checkout.
  3. Run selftest, shellcheck, and the mutant suite; stop on any non-zero exit.
  4. Ask for the consumer repo, its checks command, the worktrees directory, the executor, and the default number of workers — suggesting what loom capacity detects from Orca.
  5. Verify gh and, for Orca, the runtime and the 1.4.246 floor.
  6. Render a ticket with --dry-run and stop before opening it.

It never pushes, merges, or writes credentials to a file, and it does not claim success without a captured exit code.

After it finishes
