The aim: more accepted, verified tasks per hour of human attention. Start with one bounded task and checks you already trust.

  1. 01

    Scope

    Write the mandate: allowed files, exclusions, and what counts as done.

  2. 02

    Assign

    Give the ticket a worker and a separate workspace with the mandate.

  3. 03

    Report

    The worker leaves changes and a structured state: ready, blocked, failed, or waiting.

  4. 04

    Check

    The conductor runs your checks against the result in a fresh clone.

  5. 05

    Review

    Inspect the diff and evidence. The conductor collects; the owner controls what ships.

A passing check is evidence for review. Its coverage determines what it can tell you.

Your agent.
Your workspace.

Loom coordinates the work. It does not supply a model or replace your agent’s permissions.

Local

A private clone with its own Git history and no configured remote. Launch your agent and run Loom’s watch loop to follow its reports.

The local watchdog applies while the watch loop is running. Removing a remote is not a security sandbox.

Set up the local executor

With Orca

Orca creates and supervises the worker workspace. Its app must be running; configured compute placement requires a connected host.

Loom surfaces silent Orca workers as stale for a decision. It does not signal them with the local watchdog.
